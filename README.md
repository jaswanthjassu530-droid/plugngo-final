# PlugNgo

PlugNgo is a peer-to-peer EV charging marketplace prototype set in Kakinada, India. Drivers can explore charging stations, check vehicle compatibility and reserve a time slot. Charger owners manage ports and booking requests. An admin dashboard supports verification and network monitoring.

## Run the demo

Download the project and open `index.html` in a modern browser. No installation or build step is required. Online map tiles require an internet connection.

## Try it

1. In the Customer dashboard, open **Find stations** and pick a station.
2. Select **Book a slot**, choose a compatible vehicle and time, and review the energy estimate.
3. Confirm the demo booking and check its status in **My bookings**.
4. Use the role selector to explore the **Owner** and **Admin** dashboards.

Bookings, meter readings and payments are simulated. The demo stores changes in the browser.
